## Before anything is powered

| item | value | where it goes |
|---|---|---|
| payload mass (kitchen scale) | ______ kg | `load_mass:=` on every launch (default is 0.1, wrong) |
| rod: rim attach point → drone CoG | ______ m | `cable_len:=` (default 0.5) |
| rim magnet azimuths, clock face | __ / __ / __ o'clock | `attach_azimuths_deg:=` (3 o'clock = 0, 12 = 90, 9 = 180, 6 = 270; leave empty for even) |
| disc thickness / attach height | ______ m | `attach_z:=` (default 0.025) |
| pack voltages at start | __ / __ / __ V | flight card |
| adapter → airframe pairing | QUAD1→d_, QUAD2→d_, QUAD3→d_ | `drone<i>_serial:=` on `rio` |

Adapter trap: udev names the three ELRS adapters `/dev/QUAD1`, `/dev/QUAD2`, `/dev/QUAD3`
and the launch defaults to `/dev/QUAD0..2`, so the serial args must be passed. QUAD1 and
QUAD2 are told apart only by which USB socket they sit in. Plug in, then:

```bash
ls -l /dev/QUAD*           # all three symlinks must exist before rio
```

Mocap: rigid bodies 10, 20, 30 must be the airframes bound to the adapters you pass as
drone 0, 1, 2, and body 8 the disc. If the lab's body ids differ, edit
`RIGID_BODY_TO_DRONE` in `motion_capture_publisher_node.py` and rebuild (`cb`).

## T2 — hover at 0.6 m: kT and the height bar (2 repeats + corrections)

```bash
rctl load_mass:=M cable_len:=L attach_azimuths_deg:=A,B,C thrust_ratio:=24 lift_ramp_vel:=0.15 target_z:=0.6 load_traj:=hover
```
ARM → TAKEOFF → 20 s hover → LAND.

| bar (from `sil_smoke`) | value |
|---|---|
| settled payload z | 0.55–0.66 m |
| payload tilt peak / settled | < 15° / < 3° |
| envelope faults | none |

kT rule (a wrong kT lands in height, not throttle): payload settles **high** → raise
`thrust_ratio`; **low** → lower it. Step 5 % (24 → 25.2 or 22.8), re-fly. Falsifier for
"kT is one number": two corrections do not bring z into the band, or the band is met on a
full pack and lost on a low one → battery sag matters, calibrate `kt_batt_sag_frac`
(hover the same load on a full and a nearly flat pack, compare hover throttle).

Record per flight: pack V before/after, kT used, settled z, tilt peak, log dir.

the matching sim configs are `diss_hover_n3` and `diss_circle_n3` at 0.2 m/s.
