\subsection{Summary of Literature and Research Gaps}

Despite extensive coverage of fixed-team multi-UAV payload transport, no existing work demonstrates a strategy for adding an agent to an active mid-flight mission. The closest prior work either addresses only agent removal \cite{tensionbased}, provides dropout robustness with no mechanism for structured agent addition \cite{quan2025swarm}, or proposes join protocols without experimental validation or explicit force reallocation \cite{tasoojiCooperativeControlMultiQuadrotors}. This gap motivates the proposed direction of this thesis: a centralised dissipative architecture combining agile payload manipulation with robustness to dynamic changes in team composition.
